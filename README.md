# Handig – leer Vlaamse Gebarentaal

Een leerapp in Duolingo-stijl voor Vlaamse Gebarentaal (VGT), voor persoonlijk gebruik.

- Lessen met kennisquizzen en gebaren
- Gebarenvideo's via een videoadres uit het VGT-woordenboek of als bestand
- Camera-oefening: de app vergelijkt je handvorm, plaats en beweging met de video (indicatie, geen oordeel van een Dove gebaarder)

Alles wordt bewaard in je eigen browser. Handherkenning: MediaPipe (Google), geladen via jsDelivr.
